# week-7
I wanted to make an app that helps people keep track of their daily tasks. It lets users write down chores they need to do and set reminders so they remember to complete them at the right time. By making it easy to organize tasks and set notifications, the app aims to reduce stress and help users stay motivated throughout their day.

Planned Features:
Reminder option
No limit on how many items the user can put
Delete feature
view past chores
